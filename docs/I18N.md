# Đa ngôn ngữ — kiến trúc `locales` + `translations`

## Nguyên tắc

- **Không** thêm cột `*_vi` / `*_en` cho mỗi ngôn ngữ mới.
- Bảng **`locales`**: cấu hình ngôn ngữ (bật/tắt, mặc định, tên hiển thị).
- Bảng **`translations`**: một dòng / (entity, locale), JSON `attributes` chứa mọi field dịch (`name`, `prompt`, `explanation`, `usage`, …).
- Code đọc qua trait **`HasTranslations::localized('field')`** — thêm `zh` / `ko` chỉ cần seed/admin, không sửa PHP theo từng field.
- Cột JSON tên `attributes` — đọc qua `getAttribute('attributes')` (tránh trùng thuộc tính nội bộ của Eloquent).

## API

| Endpoint | Mô tả |
|----------|--------|
| `GET /api/v1/locales` | Danh sách locale active (public) |
| Header `X-Locale` / `Accept-Language` | Chọn locale response |

### Admin (Sanctum)

| Method | Endpoint |
|--------|----------|
| `POST` | `/api/v1/admin/locales` — thêm locale (vd. `zh`) |
| `PATCH` | `/api/v1/admin/locales/{code}` |
| `GET` | `/api/v1/admin/translations?type=tense&slug=present-simple` |
| `PUT` | `/api/v1/admin/translations` body: `type`, `slug`, `locale`, `attributes` |

## Import JSON (`packages/content`)

Ưu tiên block `translations`:

```json
{
  "slug": "present-simple",
  "structure": "...",
  "translations": {
    "vi": { "name": "Hiện tại đơn", "usage": ["..."], "pitfalls": "..." },
    "en": { "name": "Present Simple", "usage": ["..."], "pitfalls": "..." },
    "zh": { "name": "一般现在时" }
  }
}
```

File cũ vẫn chạy: seeder map `name_vi` / `name_en` / `explanation_vi` → translations.

## Web (Next.js)

- UI: `messages/vi.json`, `messages/en.json` (`next-intl`) — nhãn nút/menu.
- Nội dung grammar SSG: dần chuyển sang `translations` trong `grammar.json` hoặc fetch API.
- Thêm locale web: cập nhật `src/i18n/routing.ts` + file messages + bật locale trong DB.

## Thêm tiếng Trung / Hàn

1. `POST /api/v1/admin/locales` `{ "code": "zh", "name": "Chinese", "native_name": "中文", "is_active": true }`
2. Import/PUT translations cho từng `tense` / `question`.
3. (Tuỳ chọn) thêm `messages/zh.json` và `zh` vào `routing.locales` nếu cần UI web.

Không migrate schema.
